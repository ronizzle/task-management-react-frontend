# task-management-react-frontend

React + Tailwind CSS frontend for the Task Management & Analytics Platform. Consumes both the Laravel API and Node.js services.

Part of the [task-management](https://github.com/ronizzle/task-management) umbrella project. See that repo's `plan.md` for the full spec.

Setup instructions, test credentials, and live URL will be added here as the project is built.
